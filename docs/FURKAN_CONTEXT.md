## The Core Loop (Diagnosed)
Work inadequacy feeling
→ Mental load + fatigue during day
→ Evening emptiness / not knowing what to do
→ Passive escape: TV / YouTube / Twitter
→ Revenge Bedtime Procrastination (night = only free time feeling)
→ Late sleep (01:00–01:30) + poor quality
→ Less productive next day
→ Back to work inadequacy feeling

This loop is exactly what Sprint 4's triple correlation graph visualizes:
**Sleep Hours · Morning Activation · Evening Lost Time**.

## Design Decisions (carried forward)
- **No hardcoded personal content in app code.** All anti-goals, beliefs, goals, hyper-focus values are user-managed
- **App will eventually be open to other users** — keep generic
- **Physical notebook + digital app run in parallel** — the design ethos (paper-grid, IBM Plex Mono, ink colors) matches the notebook
- **Analog-first philosophy:** ritual over notification, no push notifications
